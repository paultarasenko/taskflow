# Features

Каждая папка здесь зеркалит backend-модуль из `backend/app/modules/`
(auth, workspace, projects, tasks, comments, notifications, ai) — тот же
принцип консистентности, что и в бэкенде (см. docs/01-architecture-and-design.md,
раздел 3). Компоненты, хуки и API-запросы конкретной фичи наполняются на
Этапе 9 (Frontend).
